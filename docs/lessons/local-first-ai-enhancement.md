# Lesson — Local-first AI enhancement

## What

The AI provider improves language after deterministic software has already decided the facts and actions.

## Why

Language models are strong at explanation but weaker as an authority for application state and verified links. Separating those jobs makes failure cheap: the local result already exists when enhancement fails.

## When to use

Use enhancement for summaries, comparisons, recruiter-oriented explanations, and more conversational phrasing.

## When not to use

Do not call AI for slash commands, downloads, opening Resume, direct contact links, or other requests the local engine already handles precisely.

## Engineering lesson

Fallback should be a complete product path, not an error handler assembled after the primary path. Running local first makes the fallback the same tested behavior users receive in Local mode.
